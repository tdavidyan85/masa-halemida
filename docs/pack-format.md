# מבנה "חבילת תוכן" (masa-pack/1)

כל מקצוע ויחידה במסע הלמידה הם **קובץ נתונים אחד (JSON)**, בלי קוד. המנוע (הקראה, רמזים, הסברים, רמות, חזרה מרווחת, מבחנים, דפי עבודה והדפסה) זהה לכל המקצועות.
כך אפשר להכין יחידה חדשה מדף עבודה – ידנית, או בעתיד אוטומטית – ולבדוק אותה לפני שהילד רואה אותה.

דוגמה מלאה: [`packs/english-pronouns.json`](../packs/english-pronouns.json) (היחידה באנגלית – שמות גוף).

## המבנה

```jsonc
{
  "schema": "masa-pack/1",
  "subject": { "id": "english", "name": "אנגלית", "grade": "ה", "unit": "Pronouns – שמות גוף" },
  "cfg": { "examInfo": "…", "testSay": "…" },          // טקסטים למסך הראשי
  "topics": [                                          // תחנות במפה
    { "id": "pro", "name": "שמות גוף", "glyph": "I", "bg": "#cfe3ff",
      "lessons": [ { "title": "…", "text": "…" } ],    // שיעור קצר: שקפים
      "skills": [ { "id": "en2he", "name": "מאנגלית לעברית", "pool": "en2he", "examQ": 1 } ] }   // סוגי תרגול
  ],
  "pools": {                                           // מאגרי שאלות
    "en2he": { "defaults": { /* שדות משותפים לכל השאלות */ }, "items": [ /* שאלות */ ] }
  },
  "exams":  [ { "name": "המבדק המקורי", "fixed": [ { "skill": "en2he", "id": "we", "label": "שאלה 1" } ] },
              { "name": "כמו דף העבודה", "sections": [ { "skill": "sentence", "n": 8, "label": "חלק א · משפט {n}" } ] } ],
  "sheets": [ { "id": "…", "name": "…", "title": "Pronouns",
                "sections": [ { "layout": "lines | story | table | row", "heading": "…", "pool": "…", "items": ["id", "…"] } ] } ],
  "legacy": { "oldName": "skillId" }                   // מעביר התקדמות משמות ישנים
}
```

## שאלה (item)

| שדה | מה זה |
|---|---|
| `type` | `choice` (בחירה) · `number` (מספר) · `fraction` (שבר) · `spell` (כתיבת מילה באותיות) · `multi` (כמה שלבים, ב-`parts`) · **מנגנוני אינטראקציה כלליים, לכל מקצוע:** `sort` · `match` · `order` · `tap` · `cells` (ראו הסעיף למטה) |
| `text`, `visual`, `sub` | השאלה, מה שמוצג בגדול, ושורת עזר קטנה (למשל תרגום) |
| `paperText` | נוסח השאלה במבחן / בדף (כמו בדף המקורי) |
| `options`, `answer`, `alts` | אפשרויות (`"טקסט"` או `{ "t": "…", "v": "ערך" }`), התשובה, ותשובות נוספות שמתקבלות |
| `show`, `shuffle` | כמה אפשרויות להציג (מתוך הרשימה), והאם לערבב |
| `accept` | למספר: כל תשובה בטווח נכונה – `{ "min": 4, "max": 5, "exclusive": true }` |
| `hint`, `steps`, `mistakes` | רמז, הסבר שלב אחרי שלב, והסבר לטעות מסוימת: `{ "they": "יש בפנים I…" }` |
| `line`, `paper`, `paperLine` | מה נכתב ב"הדרך שלי", ב"ככה כותבים בדף", ובדף להדפסה |
| `vars` | שאלה עם מספרים משתנים: `{ "a": [2, 9], "b": { "pick": [10, 20, 30] }, "c": { "calc": "a*b" } }` ואז בטקסט `{a}` ו-`{=a*b}` |
| `guided` | ב-`multi`: השלבים מודרכים, ורק האחרון נבדק במבחן |

## מנגנוני אינטראקציה (`sort`, `match`, `order`, `tap`, `cells`)

הילד עושה משהו עם הפריטים, והמנוע בודק. הם לא תלויים בנושא: אפשר למיין בעלי חיים, חלקי דיבר או שברים. רמזים (`hint`), הסבר שלב אחרי שלב (`steps`), טעויות (`mistakes`), רמות, מבחנים והקראה עובדים כמו בכל שאלה. טקסטים בכל השדות תומכים בסימון (`<f>`, `<en>`, `{a}`…) ובמשתנים (`vars`).

| סוג | שדות | הילד |
|---|---|---|
| `sort` | `bins: ["א","ב"]`, `items: [{ "t": "…", "bin": 0 }]` (`bin` = מספר או שם הקבוצה) | לוחץ על פריט ואז על הקבוצה שלו |
| `match` | `pairs: [{ "l": "…", "r": "…" }]` | לוחץ על פריט בצד אחד ואז על הפריט המתאים |
| `order` | `items: ["ראשון","שני",…]` (רשומים **בסדר הנכון**, המנוע מערבב) | לוחץ על הפריטים לפי הסדר |
| `tap` | `tokens: ["The", { "t": "cat", "ok": true }, …]` (`ok` = נכון ללחוץ) | לוחץ על כל המילים הנכונות |
| `cells` | `shape: "pie" או "bar"`, `parts`, `wholes` (ברירת מחדל 1), `count` | צובע בדיוק `count` חלקים (לא משנה אילו) |

כללים לבדיקה (`validatePack`): ב-`sort` שתי קבוצות ושני פריטים לפחות, בלי כפילויות ו-`bin` תקין; ב-`match` צד שמאל וצד ימין ללא כפילויות; ב-`order` ללא כפילויות; ב-`tap` לפחות `ok` אחד; ב-`cells` `parts` 2–12, `wholes` 1–6, ו-`count` בין 1 ל-`parts × wholes`. מספרים משתנים אפשר לשים בכל שדה (`"count": "{=d+k}"`).

**מראה (ילדים / נוער):** נקבע לפי הכיתה בחבילה (`subject.grade`): כיתות א׳–ו׳ (או 1–6, או חסר) = ילדים, מכיתה ז׳ ומעלה = נוער. אפשר לדרוס ב-`cfg.look` (`"kids"` או `"teen"`). הצבע נושא משמעות אחת: פריט ניטרלי (חול) עד שהוא נכנס לקבוצה, ואז הוא לובש את צבע הקבוצה. ✓ ו-✗ מופיעים על הפריט ולא רק כצבע. מראה הילדים: צבעוני, צל תחתון, עוגייה, קונפטי קטן. מראה הנוער: חיוור יותר, שטוח, בלי קונפטי. המראה חל על כל המשחק (מפה, שאלות, מבחנים, חנות, מנגנוני האינטראקציה והקונפטי), ובדפוס ההדפסה אין שינוי. הוא נקבע ב-`<html data-look="kids|teen">`.

דוגמה: [`packs/math-fractions.json`](../packs/math-fractions.json) (שברים), ובדיקה לנושא אחר ב-`src/tests/tboard.js`. הקוד: `src/board-engine.js`.

## כתיבת טקסט (בטוח – כל השאר מוצג כטקסט רגיל)

`<en>…</en>` אנגלית (מוקראת בקול אנגלי) · `<m>…</m>` חשבון · `<f>3/4</f>` שבר · `<mx>2 1/3</mx>` מספר מעורב · `**מודגש**` · `___` מקום ריק · ירידת שורה = שורה חדשה.

## בדיקה

`node tools/validate-pack.js packs/<file>.json` טוען את החבילה במנוע האמיתי ובודק: תשובה קיימת באפשרויות, אין כפילויות, ביטויים מחושבים תקינים, כל סוג תרגול נוצר 100 פעמים בלי שגיאה, כל המבחנים נבנים וכל הדפים מודפסים.
